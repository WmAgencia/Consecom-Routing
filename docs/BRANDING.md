# Diretriz de comunicação

## Posicionamento

A Consecom AI permite utilizar modelos disponibilizados pela plataforma dentro do Claude Code Desktop e da CLI.

## Linguagem pública

- Falar em compatibilidade com Claude Code.
- Usar os nomes públicos e perfis de modelos apresentados pela Consecom.
- Explicar instalação, consumo, franquia e suporte em termos do produto.
- Evitar nomes de fornecedores de infraestrutura e detalhes de roteamento.
- Não prometer vínculo oficial, assinatura oficial ou parceria com a Anthropic.

## Descrição recomendada

> Use a API da Consecom AI no Claude Code Desktop ou na CLI, com uma única chave e modelos preparados para diferentes níveis de tarefa.

## Nota jurídica

Claude e Claude Code são marcas de seus respectivos titulares. A Consecom AI é um serviço independente de compatibilidade de API.
