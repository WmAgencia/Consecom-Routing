# Segurança

Não abra issues públicas contendo chaves, cookies, URLs de banco, hashes de senha ou dados de clientes.

Credenciais devem existir somente no gerenciador de variáveis da Railway. O repositório contém apenas nomes de variáveis e exemplos vazios.

Se uma credencial aparecer em um commit, ela deve ser revogada e substituída. Apagar o arquivo em um commit posterior não remove o segredo do histórico.

Para relatar uma vulnerabilidade, use um canal privado do responsável pelo projeto.
